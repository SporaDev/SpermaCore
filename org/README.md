## 🧬 О нас / About SporaDev

**SporaDev** — независимая инженерная лаборатория, сфокусированная на разработке высокопроизводительных рантаймов, низкоуровневых системных интерфейсов и отказоустойчивых автономных ИИ-ассистентов.

## ⚡ Флагманский проект: [SpermaCore](https://github.com/SporaDev/SpermaCore)

> **Модульный, отказоустойчивый рантайм для автономных LLM-ассистентов и Telegram-юзерботов.**

- 🛡️ **Crash Immunity**: сбой в нативном C++ модуле изолируется ядром Go без падения основного процесса.
- 🧠 **Векторный RAG (HNSW)**: субмиллисекундный поиск релевантного контекста на C++20.
- ⚡ **Telegram TDLib**: полноценный нативный юзербот (QR-авторизация, управление медиа, реакции, эмуляция набора текста).
- 🔀 **LLM Multi-Router**: единый интерфейс для OpenRouter, Groq, Ollama и мультимодальных моделей (Gemini Vision).
- 🖥️ **WebUI & Real-time Telemetry**: встроенная веб-панель мониторинга и управления.
